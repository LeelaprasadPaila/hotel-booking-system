# 🏨 Hotel Booking System

A modern and responsive **Flask-based Hotel Booking System** that provides a complete hotel management experience. The application features an elegant luxury hotel landing page with room booking, restaurant ordering, payment processing, and booking records through a clean and user-friendly interface.

# ⚙️ Backend API Routes

| Route | Method | Description |
|--------|--------|-------------|
| `/` | GET | Homepage |
| `/api/rooms-info` | GET | Returns room details |
| `/api/booking` | POST | Creates a new booking |
| `/api/payment` | POST | Looks up a booking for payment |
| `/api/confirm-payment` | POST | Confirms payment |
| `/api/restaurant` | POST | Adds restaurant charges |
| `/api/records` | GET | Returns booking records |

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/your-username/luxury-hotel-booking-system.git
```

## Navigate to the Project Folder

```bash
cd luxury-hotel-booking-system
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python backend/app.py
```

## Open in Browser

```
http://127.0.0.1:5000
```

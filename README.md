# Aurelia Grand Hotel

A polished Flask-based hotel booking website with a premium landing page, room selection, booking flow, restaurant ordering, payment handling, and records.

## Project structure

- `index.html` — frontend entry page
- `static/` — CSS and JavaScript assets
- `backend/app.py` — Flask backend and API routes
- `test.py` — console-based demo version

## Run locally

1. Create and activate a virtual environment
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the app:
   ```bash
   python backend/app.py
   ```
4. Open http://127.0.0.1:5000/

# ⚙️ Backend API

| Route | Method | Description |
|--------|--------|-------------|
| `/` | GET | Homepage |
| `/api/rooms-info` | GET | Returns room details |
| `/api/booking` | POST | Create a booking |
| `/api/payment` | POST | Find booking for payment |
| `/api/confirm-payment` | POST | Confirm payment |
| `/api/restaurant` | POST | Add restaurant charges |
| `/api/records` | GET | View booking records |

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/luxury-hotel-booking-system.git
```

Move into the project folder

```bash
cd luxury-hotel-booking-system
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Flask application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
